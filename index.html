Settings & OneDrive Sync

Connect to a OneDrive file

Store this HTML file in your OneDrive folder. Click the button below to connect and enable auto-save so every change is written back to the same file.

1) Move this FinanceHub.html file into a OneDrive-synced folder.

2) Open it from that folder (double-click in Explorer/Finder).

3) Click Save to File once to grant write access.

4) All changes auto-save; close and reopen on any device with OneDrive to continue where you left off.

Auto-Save & Sync Tips

  • Auto-save is enabled when connected (green status pill at bottom-right).
  • File handles are session-based; after a browser restart, click “Connect / Save to File” once to re-authorize.
  • Keep the file name unchanged while it’s open.
  • For shared access, share the OneDrive folder; all collaborators open the same HTML file.
  • If a device can’t connect, use “Download Backup” under Reports to capture your latest data.
Need to reconnect fast? Use the floating Save button (bottom-right) anytime.
